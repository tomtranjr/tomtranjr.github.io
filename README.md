# Tom Tran Jr – Personal Website & Portfolio

This repository contains the source code for my personal website, built to showcase my resume, project portfolio, and professional background. The site is deployed using GitHub Pages at: [https://tomtranjr.github.io](https://tomtranjr.github.io)

It includes:
- A dynamic resume (CV)
- A project portfolio
- Blog space for personal and technical writing

## 🚀 Getting Started Locally

To run the site locally:

```bash
bundle install
bundle exec jekyll serve
```

Then visit `http://localhost:4000` in your browser.

You may need to install Ruby and Bundler:
```bash
brew install ruby
gem install bundler
```
