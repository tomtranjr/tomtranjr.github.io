This is a draft. It shows up in `npm run dev` and is left out of production builds.

To publish a post, add a Markdown file to `src/content/blog/` with a `title`, `description`, and `pubDate`. Leave out `draft`, or set it to `false`.

A post can be a few thoughts, a write-up, or a list of links worth sharing:

- [Astro docs](https://docs.astro.build)
- [Markdown guide](https://www.markdownguide.org/basic-syntax/)
